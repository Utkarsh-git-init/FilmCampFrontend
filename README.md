# FilmCamp Frontend
A sleek, responsive interface for discovering and managing your cinematic journey.

## Key Features

*   Dynamic Discovery: Browse trending and top-rated movies powered by the TMDB API.
*   Personal Watchlists: Add or remove films from your personal collection.
*  Real-time Search: Instantly find movies using a debounced search bar.
*  Secure Authentication: Integrated JWT-based login and registration flows.

---

## Tech Stack

* Framework: React.js
* Styling: CSS Modules
* State Management: Context API
* Data Fetching: fetch
